# Diretrizes do AGRO Gestão

Documentos originais recebidos do produtor. O app embarca só os resumos em `app/public/knowledge/` (premissas de interface, estoque e engajamento); estes arquivos completos não vão dentro do APK.

- `Diretrizes_Inteligencia_Territorio_Gestao.docx` — inteligência e orientações do app
- `Diretrizes_financeiras_inteligencia_produtor.docx` — regras financeiras para o produtor
- `Engajamento_Design_Agro_Gestao.docx` — engajamento e design
- `Regras_Janelas_Desempenho_Agro_Gestao.docx` — janelas, desempenho e testes
- `Politica_dados_demonstracao_operacao_real.docx` — separação entre demonstração e operação real
- `Guia_Apple_HIG_para_criar_apps_no_Codex.docx` — guia de interface no estilo Apple
- `Agro_Gestao_Diretrizes_Voz_Vosk_Android.docx` — vender por voz (Android + Vosk offline); versão 1.2 com a revisão da implementação
